# The World in One Image — Wednesday 18 November 2026

A single 1024×1024 poster summing up 18 November 2026's world news:
US–Iran strikes in the Gulf, the Kerch Bridge hit again, the first-ever
Trump–Xi–Putin trilateral summit set for 19 Nov, the Ebola surge in DR
Congo, Cyclone Akvan, the US losing its measles-free status, Nvidia's
doubled revenue, and Gaza.

`main.py` (Python 3.13, standard library only) copies the bundled
`entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`. Running it twice produces
byte-identical output. `poster.html` is the poster source used to render
`entry.png`.
