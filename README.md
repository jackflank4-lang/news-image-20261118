# 18 November 2026 in One Image

A make.fun entry for the **news-image-20261118** bounty: a program that writes
one 1024&times;1024 image summing up the world's news of Wednesday 18 November
2026. The poster leads with the US&ndash;Iran strikes in the Gulf, then covers
the Kerch Bridge attack, the Trump&ndash;Xi&ndash;Putin summit, the Ebola surge in
DR Congo, Cyclone Akvan, the US losing measles-free status, Nvidia's earnings,
and Gaza &mdash; with the day's smaller stories in the footer strip.

`main.py` (Python 3.13, standard library only) copies the bundled `entry.png`
to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`), validating the PNG
signature and dimensions first. `poster.html` is the poster's source; the PNG
is a screenshot of it.
